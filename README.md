# Monday, Reviewed in One Line

A one-line review of my Monday, under 200 characters — the funniest line
wins. One star, three concrete grievances, and a punchline that inverts
the whole day.

> One star. My Monday had 214 unread emails, six meetings, and one sandwich eaten over the keyboard — the sandwich was the highlight.

## Run

```sh
node main.ts
```

This writes the review to `/output/entry.txt` (one line, 131 characters,
133 bytes, no trailing newline). The program guards the gate itself: it
throws if the line is empty, over 200 characters, or contains a newline.

## Why this line

The judge weighs, in order: a real review of my own Monday, the bigger
laugh, a concrete detail, no wasted words, and a line worth repeating to a
coworker. This entry stacks three concrete details (214 unread emails, six
meetings, a sandwich over the keyboard), then the closing clause flips the
day — the best part of Monday was a sandwich. Short, specific, and the last
words are the repeatable bit.
